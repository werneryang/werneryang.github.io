ChatGPT Chat Exporter

A local-first Chrome extension for collecting, filtering, deduplicating, and exporting your ChatGPT conversations.

Features

  • Export the current conversation, or select multiple chats from a local library.
  • Import official ChatGPT export ZIP or JSON files.
  • Export Markdown, JSON, or use Chrome’s print dialog to save as PDF.
  • Filter by date, search message text, and merge exact duplicates locally.

Usage notes

This is a Chrome extension, not a web app. Conversation data stays in browser-local storage; no server, telemetry, or AI API key is used. Experimental live-history sync uses private ChatGPT endpoints and is not verified for authenticated retrieval. Use official export import for dependable batch backups. Images, voice, generated files, and complex interactive content may be omitted.

An independent personal project, not affiliated with or endorsed by OpenAI.
