ChatGPT 对话导出工具

在 Chrome 中收集、筛选、去重和导出自己的 ChatGPT 对话，数据保存在浏览器本地。

功能

  • 导出当前对话，或从本地对话库中选择多条批量导出。
  • 导入 ChatGPT 官方导出的 ZIP 或 JSON 文件。
  • 导出 Markdown、JSON，或通过 Chrome 打印对话框保存为 PDF。
  • 按日期筛选、搜索消息内容，并在本地合并完全重复的对话。

使用说明

这是 Chrome 扩展，需要在浏览器中安装。对话数据保存在浏览器本地，无服务端、遥测或 AI API 密钥。实验性历史同步依赖 ChatGPT 私有接口，尚未验证登录后的完整获取流程；可靠的批量备份请使用官方导出文件导入。图片、语音、生成文件和复杂交互内容可能无法保留。

个人独立项目，与 OpenAI 无隶属或背书关系。
